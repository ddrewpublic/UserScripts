## Userscripts for Tampermonkey

Browser scripts to make some sites more tolerable and add a bit of QOL.

1. ChatGPT Bottom Area Resizer
   - add a handle to the ChatGPT input box, so that it can be moved around the screen.<br><br>
1. Link Rewrite
   - initially written to remove a referrer string from links on ChatGPT.
   - modified to work on *any* url, and to include *adding* strings.
1. Mistral AI Widescreen
- Expands the chat interface to full width (90vw), making messages and the input box easier to read and use.
- Compact toggle button (bottom-right) labeled "W" that expands on hover—click to enable/disable widescreen mode.
